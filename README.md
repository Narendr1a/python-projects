# Simple Calculator

A menu-driven Python calculator with:

- Addition, subtraction, multiplication, division, modulo, floor division, and powers
- Base-10 and natural logarithms, and exponentials
- Trigonometric functions, square root, and basic statistics

Run it from the project folder with:

```bash
python Calculator/simple_calculator.py
```

Python 3.10 or newer is required. Enter `10` at the main menu to exit.

Some options have input limitations in the current implementation: trigonometric input does not work as intended, and statistical values are read one character at a time.
